Azeroth Survivors — Save Editor

An unofficial editor for the saves of Azeroth Survivors, the fan-made survivors-style roguelike set in vanilla Azeroth. It unseals an exported .sav, lets you edit heroes, talents, zones and heroic tiers, the gear collection and its stars, companion perks, statistics and achievements, and seals it again for import. Everything runs in this page; nothing is uploaded. Keep a backup of your original save: an import replaces what is in the game. Not affiliated with the game or its developer.
