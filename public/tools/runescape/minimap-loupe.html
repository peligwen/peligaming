Minimap Loupe

A RuneLite plugin. Put the cursor on the minimap and a small circle of it comes up magnified under the pointer — the way a loupe sits on a chart.

Old School RuneScape · RuneLite · sideloaded

Download the jar
minimap-loupe.jar

Built from runelite/minimap-loupe in this site's repository — MIT, and small enough to read in a sitting.

What it looks like

Move the pointer over the disc. This is a stand-in map, not the game — but the lens is the same maths at the same defaults, so the settings you like here are the settings to type into RuneLite.

Installing

This plugin is served from here rather than RuneLite's Plugin Hub, so the client loads it as a sideloaded plugin. That takes two things: the jar in the right folder, and a client started in developer mode.

  1. Put the jar in the sideload folder. Create it if it isn't there yet:
    • Windows — %USERPROFILE%\.runelite\sideloaded-plugins\
    • macOS / Linux — ~/.runelite/sideloaded-plugins/
  2. Start RuneLite in developer mode. Open the launcher's configuration — the RuneLite (configure) start menu entry on Windows, or /Applications/RuneLite.app/Contents/MacOS/RuneLite --configure on macOS — and add --developer-mode to Client arguments. Launch as normal afterwards.
  3. Turn it on. The plugin panel now lists Minimap Loupe; tick it, and the cog beside it opens the settings below.

Developer mode is RuneLite's own gate on plugins it hasn't reviewed — every sideloaded plugin needs it, not just this one. It changes nothing else about the client. A jar from a Plugin Hub listing would install with one click instead; that's a submission to RuneLite's own repository, and this plugin isn't in it.

To update, replace the jar and restart the client. To remove it, delete the jar.

Settings

SettingWhat it does
Magnification110%–800%. The default 250% is about where a dot cluster becomes countable; past 400% you are looking at large squares.
Lens radius16–200 px. How big the circle on screen is.
Lens positionOn the cursor, like a glass laid on the map, or Beside the minimap, parked to its left so the map is never covered.
SmoothBlend the enlarged pixels, or show them as hard blocks.
Show rim / Rim colour / Rim widthThe ring around the lens.
Show crosshairMarks the exact point under the pointer at the centre of the lens. Most useful with the lens parked.
Hold to showBind a key and the lens only comes up while it's held. Leave it unset and the lens is up whenever the cursor is on the map.

What it can and cannot do

The client draws the minimap once, at one scale, into the frame it puts on screen. There is no sharper copy of it to enlarge — so the lens magnifies pixels that are already on your screen. It makes a crowded cluster of dots or a cramped icon readable. It does not reveal anything the client had not already drawn, and it does not know anything the game did not put on screen.

Reading the finished frame does have one nice consequence: whatever other plugins draw on the minimap is in those pixels too, so their dots and markers come up magnified along with the map.

Where the circle reaches past the edge of the map it fills with flat dark rather than magnifying the interface around it. And anchored to the cursor the lens is drawn over the very patch it reads — the client repaints the map every frame, so it reads fresh pixels, but parking the lens beside the minimap sidesteps the question entirely.
